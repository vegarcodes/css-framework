# Rammeverk for styling av nettsider

**tl;dr:** Dette er en starter for å skrive moderne, velfungerende CSS. Det er tatt noen valg, men ikke flere enn at de er lette å gjøre om hvis du trenger. Tanken er at dette repoet skal fungere som en boilerplate for videre arbeid, så ikke regn med at noe her ser spesielt pent ut. Du må fremdeles, vel, designe greia sjøl.
